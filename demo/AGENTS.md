# 本目录仅供临时演示

本文件适用于 `demo/` 及其所有子目录。

## 必须保留的声明

**本目录全部内容仅用于临时演示。正式开发不得以本目录的设计、代码、数据、接口、测试或结果作为参考、实现依据、验收依据或事实证据。**

允许在本目录内使用固定数据、预设流程、模拟调用和简单规则，但不得将这些内容移入正式产品，不得把演示完成写成正式能力完成。

## 工作边界

1. 后续实现遵循本目录 `DESIGN.md`，该文档仅约束演示版。它不修改、不替代正式需求、正式契约及正式技术路线。
2. 未有用户新的明确要求时，修改范围限制在 `demo/` 内。本次创建目录的授权不包含修改正式源码、依赖、契约、测试或已有运行产物。
3. 演示服务不得导入 `game_app`、`game_collector`，不得读写正式数据库、密钥或 `runs/`；正式模块也不得依赖本目录。
4. 资源、样例、测试和状态均本地自包含；不得依赖 CDN、在线字体、真实搜索、真实模型、硬件探测、真实采集工具或游戏进程。
5. 只在 `demo/runtime/` 创建运行数据、上传副本和导出文件。重置仅作用于本目录的演示状态与受管理产物，不接受任意文件路径。
6. 按用户后续明确要求，玩家页面不展示演示标识；开发文档、数据元信息和导出保留演示性质。模拟采集不能写成“实测”，模拟来源不能冒充真实作者或真实引用，配置确认不能写成已自动修改游戏。
7. 当前唯一活跃案例为 RTX 4060＋使命召唤：现代战争 I。内部保留 `mw2-rtx4060` 和旧游戏 ID 以兼容已有记录；地平线资源仅内部归档，不进入玩家页面。
8. “检查本机信息”按用户授权返回固定设备档案，不执行真实探测。未知的游戏条件仍可编辑，不把设备预设或虚拟日志当作真实采集证据。
9. 每次操作应真实改变演示状态；查询接口不推进流程。保存、采用、回滚、刷新恢复、重试、取消和重置需保持数据关系一致。
10. 演示测试使用本目录样例及临时目录，独立运行、独立报告；不得将其通过数混入正式项目功能完成报告。

用户已授权实现并启动独立演示服务。后续修改继续限制在本目录，并遵循 `DESIGN.md` 最新章节；本轮交互包括 3 秒回复、回复后约 1 分钟建卡、内部滚动的聊天、分组设置和三份虚拟游玩日志。
