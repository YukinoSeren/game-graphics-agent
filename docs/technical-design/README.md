## 6. 编号、版本与检查方式

- 现有 C/R/D 编号原样保留；H、Q、B-DEC 为引用或决策标签，不覆盖它们。
- 基础契约验收用 `B-DAT-*`、`B-STA-*`、`B-ERR-*`；C 阶段用 DEV/KNW/REC/PERF/FBK/UX/ENG/VAL 前缀，并链接关联需求。

- 审阅修订后的共享基线为 `product-contract/0.2`；0.1 产品对象的读取映射见 data §12，旧幂等记录按原 request_schema_version/hash/响应读取，不借升级重新执行。公共知识版本仍为 `0.1`。
- 本轮复核：本地链接、Markdown 表格/示例、引用字段与状态名称、P0 追踪、D01—D05 的共享支撑及修改范围。契约验收表是待实现用例，不报告为程序已经通过。
